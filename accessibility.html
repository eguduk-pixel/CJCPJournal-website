Accessibility

Using the journal

Use the “Skip to main content” link when navigating by keyboard. Interactive controls have visible focus indicators, and the public layout adapts to smaller screens. In a narrow editorial workspace, use “Editorial navigation” to expand the menu; wide tables can be scrolled horizontally.

Article formats

Accessible HTML and downloadable PDFs are planned for published articles. No articles have been published yet, so article-format accessibility has not been verified for live content.

Ongoing checks

Keyboard, contrast and responsive checks are part of development. Representative screen-reader testing and a full accessibility review remain outstanding; this page does not claim accessibility certification.

Report a barrier

CJCP participants can report a page, control or document that is difficult to use to Dr. Guduk through existing school channels. Include the page title, device or browser and the step that was difficult. Do not include passwords or confidential manuscript content.
